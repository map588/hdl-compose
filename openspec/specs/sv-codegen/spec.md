## ADDED Requirements

### Requirement: Generate module declaration from top-level ports
The codegen SHALL emit a SystemVerilog module declaration using `Schematic.top_name`, `top_generics` (as parameters), and `top_ports`.

#### Scenario: Module with parameters and ports
- **WHEN** a schematic has top_name `"top_level"`, parameter `CLK_FREQ = 100000000`, and ports `input wire clk` and `output wire [7:0] led`
- **THEN** output SHALL contain a valid `module top_level #(...)(...);` declaration

### Requirement: Generate wire declarations for internal nets
For each net driven by an instance output that connects to at least one other port, the codegen SHALL emit a `wire` or `logic` declaration. The name SHALL be the user alias if set, otherwise `<driver_instance>_<driver_port>`.

#### Scenario: Wire with alias
- **WHEN** net driven by `("u_pll", "clk_out")` has alias `"sys_clk"` and is single-bit
- **THEN** output SHALL contain `wire sys_clk;`

#### Scenario: Wire without alias, multi-bit
- **WHEN** net driven by `("u_adc", "data_out")` has no alias and type is 8-bit vector
- **THEN** output SHALL contain `wire [7:0] u_adc_data_out;`

### Requirement: Generate instance statements
For each instance, the codegen SHALL emit a SystemVerilog module instantiation with parameter overrides and port connections.

#### Scenario: Instance with parameters and ports
- **WHEN** instance `u_fifo` of module `fifo_sync` has `DEPTH = 1024` and `.clk(clk_sys)`
- **THEN** output SHALL contain `fifo_sync #( .DEPTH(1024) ) u_fifo ( .clk(clk_sys), ... );`

#### Scenario: Unconnected port
- **WHEN** instance port `full` has no mapping
- **THEN** the port connection SHALL read `.full()`

#### Scenario: Port connected to internal net
- **WHEN** instance port `din` is mapped to `NetRef::InstancePort("u_adc", "data_out")` with no alias
- **THEN** the port connection SHALL read `.din(u_adc_data_out)`

### Requirement: Instances ordered alphabetically
Same as VHDL — instance statements SHALL appear in alphabetical order by instance name.

#### Scenario: Stable ordering
- **WHEN** instances `u_fifo`, `u_adc`, `u_dsp` exist
- **THEN** they SHALL appear in order: `u_adc`, `u_dsp`, `u_fifo`

### Requirement: Header comment
The output SHALL begin with `// Generated by hdl-compose. Edit the source .hdlc project file, not this file.`

#### Scenario: Header present
- **WHEN** codegen produces output
- **THEN** the first line SHALL be the header comment

### Requirement: Codegen refuses on validation errors
Same contract as VHDL — codegen SHALL NOT produce output if the schematic has validation errors.

#### Scenario: Validation error blocks codegen
- **WHEN** a schematic has a missing instance reference error
- **THEN** codegen SHALL return an error instead of producing output

### Requirement: No component declarations needed
Unlike VHDL, SystemVerilog does not require component declarations. Modules are instantiated directly by name.

#### Scenario: No component section
- **WHEN** codegen runs for SystemVerilog
- **THEN** output SHALL NOT contain any component declarations — only wire declarations and instance statements
